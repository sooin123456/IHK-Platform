# 한길시스템 BIM 적산 플랫폼

React Router와 Supabase를 사용하는 한길시스템의 회사·고객 프로젝트 웹앱입니다.

## 현재 기능

- 회사 소개, 회사 소식 뉴스룸·RSS(`/news.xml`), 저장되는 프로젝트 문의, Revit 2025 무료 베타 다운로드
- 비밀번호 없는 이메일 링크 로그인과 고객별 비공개 프로젝트
- `문의 접수 → 견적 검토 → 작업 확정 → BIM 모델링 → 물량산출 → 전문가 검토 → 납품 완료` 상태
- IFC/QTO/요소 원장 등 원본 파일의 SHA-256 보존과 검토 기록
- 요소 원장 결정론적 규칙 점검, 개정 연결, 콘크리트 산출·L1 검산 결과와 사람 승인 이력
- 별도 웹 흐름의 콘크리트 자재계획, 내부 발주, 현장 입고 확인, 계산서 증빙 3자 대조와 A1-A3 탄소
- 읽기/검토 공유 링크와 한길시스템 담당자 문의함
- 소유자 RLS 및 Supabase `auth.app_metadata.role=hangil_staff` 기반 담당자 접근

AI 기능은 현재 제품 범위에서 제외했습니다. 자동 점검은 버전이 고정된 규칙만
사용하며 수량·금액·승인을 만들지 않습니다.

## 설정

`.env.example`을 기준으로 Supabase URL·anon key를 구성합니다. 공식 베타 ZIP은
배포 파일을 별도 Windows 검증한 뒤 `VITE_REVIT_2025_BETA_URL`과
`VITE_REVIT_2025_BETA_SHA256`을 함께 등록해야 다운로드 버튼이 활성화됩니다.
배포 URL은 HTTPS만 허용합니다.
표시할 릴리스명은 `VITE_REVIT_2025_BETA_VERSION`에 입력합니다. 현재 베타는
0원이며 결제정보를 받지 않습니다. 오해 가능성이 있는 Toss/NFT 데모 코드는
제거했습니다. 유료 전환 전에는 서버가 발급한 주문, 결제 승인 검증,
다운로드 권한과 환불 정책을 별도로 구현해야 합니다.
서비스 role key를 브라우저 변수에 넣지 마십시오.

```bash
npm install
npm run typecheck
npm run build
npm run test:public
```

DB에는 `sql/migrations/0002`부터 `0010`까지 순서대로 적용합니다. `0006`은
결정론적 규칙 점검만 허용하며, `0009`는 문의함과 익명 Auth 세션 차단 RLS를
함께 구성합니다. `0010`은 콘크리트 자재관리 실증 데이터만 추가하며 모든 기록을
append-only로 보존합니다.

## 제품 분리 원칙

- Revit 설치 프로그램은 Properties·QTO·IFC·요소 원장을 추출하는 독립 제품입니다.
- 웹 플랫폼은 추출 파일을 업로드받아 물량·발주·입고·계산서·탄소 근거를 연결합니다.
- 연결 기준은 파일 확인번호와 Element ID이며 한쪽 장애가 다른 쪽 실행을 막지 않습니다.
- 웹 플랫폼은 회계전표, 세금계산서 발행, 결제, 창고재고와 공급업체 마켓플레이스를 제공하지 않습니다.
