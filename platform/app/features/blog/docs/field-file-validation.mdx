## 테스트용 모델이 아닌 실제 파일을 사용했습니다

한길시스템은 실제 Revit 프로젝트에서 IFC, QTO 집계표, 요소 원장과 거푸집 Face 원장을 내보내 각 결과가 열리는지 확인했습니다.

검증의 핵심은 파일이 생성됐다는 사실만이 아닙니다.

- QTO에 포함된 Element ID와 요소 원장의 ID 집합이 같은가
- 부피가 없는 요소와 실제 부피가 0인 요소를 구분하는가
- 결과 파일의 행 수와 산출 근거 기록의 행 수가 같은가
- 파일을 수정하면 파일 확인번호가 달라지는가
- 같은 경로의 기존 파일을 조용히 덮어쓰지 않는가

## 아직 사람이 확인해야 하는 부분

Revit 업데이트 버전별 실제 API 동작, 모델링 방식에 따른 속성 차이, 거푸집 접촉면과 공제 기준은 Windows와 실제 Revit 환경에서 계속 검증해야 합니다.

확인되지 않은 값은 PASS로 처리하지 않고 REVIEW 또는 NOT_EVALUATED 상태로 남깁니다.
