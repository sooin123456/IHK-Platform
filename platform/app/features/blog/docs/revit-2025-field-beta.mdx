## 이번 베타에서 확인할 것

Lukas QTO의 첫 목표는 복잡한 적산 판단을 자동화하는 것이 아니라, **Revit 객체의 이름과 기본 속성, 부피·면적·길이·높이를 정확하게 꺼내는 것**입니다.

현장 테스터는 소스코드나 .NET SDK를 설치하지 않습니다. 검증된 ZIP을 내려받아 설치 파일을 실행하고, Revit에서 Lukas QTO 탭과 내보내기 기능을 확인합니다.

## 왜 파일 확인번호를 같이 제공하나요?

다운로드한 파일이 한길시스템에서 검증한 파일과 정확히 같은지 확인하기 위해서입니다. 파일 이름이 같아도 내용이 달라질 수 있으므로 릴리스마다 고유한 파일 확인번호(SHA-256)를 함께 공개합니다.

## 현재 지원 범위

- Autodesk Revit 2025
- 선택 요소, 활성 뷰 또는 전체 호스트 모델 범위
- Element ID와 카테고리·패밀리·타입·레벨
- 원본 속성의 부피·면적·길이·높이
- IFC·QTO·요소 원장 패키지 내보내기

베타 결과는 자동으로 최종 적산값이 되지 않습니다. 먼저 추출값과 모델 요소가 정확히 연결되는지 현장 파일로 검증합니다.
