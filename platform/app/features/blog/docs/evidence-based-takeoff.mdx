## 숫자 하나만으로는 검토할 수 없습니다

적산 결과가 450.781m³라고 적혀 있어도 어떤 모델, 어떤 요소, 어떤 보정 규칙을 사용했는지 알 수 없다면 다시 검토하기 어렵습니다.

Lukas QTO는 다음 정보를 분리해 보존하는 방향으로 개발하고 있습니다.

1. Revit과 IFC에서 직접 확인한 기본수량
2. 할증·공제·절사와 같은 계산 규칙
3. 실무자가 수정한 보정수량
4. 최종 승인자와 승인 시점
5. 입력 파일과 결과 파일의 고유 확인번호(SHA-256)

## 자동화보다 결정론적 계산을 먼저

현재 Lukas QTO는 AI 기능을 사용하지 않습니다. 중복 Element ID, 속성 누락, 개정 차이는 공개된 결정론적 규칙으로만 점검하며, 최종 수량과 금액은 같은 입력에 항상 같은 결과를 내는 계산식과 사람의 승인으로 확정합니다.

이 구분이 있어야 자동 점검이 잘못되더라도 원본 수량과 계산 결과가 오염되지 않습니다.
