# L1.4.3 검산식 카탈로그

L1.4.3은 L1.4.1의 소스 게이트와 계산식을 유지하고 QTO 요소 추적·XLSX 저장값·입출력 안전 불변식을 강화한다. Excel 숫자는 숫자 타입과 저장값이 확인된 셀만 받아 Excel의 유효 정밀도로 정규화한 뒤 decimal 계산에 사용한다. 안전한 정수 정밀도 범위를 넘거나 저장값이 없는 수식은 입력 오류다.

## S000~S005 — 소스 승인 게이트

- S000: 사용자가 `--unsafe-no-source-gate`를 명시한 진단 실행을 REVIEW로 기록한다.
- S001: 소스 매니페스트 형식, 상대경로 경계, 파일 존재와 SHA-256을 확인한다.
- S002: 선택된 QTO·내역·매핑이 정확한 slot으로 등록됐는지 SHA-256으로 확인한다.
- S003: 세 입력의 `scope_id`가 하나인지 확인한다.
- S004: 각 입력이 해당 범위·slot의 유일한 최신 `ACTIVE`인지 확인한다.
- S005: 관련 원본이 선언된 XLSX `DERIVATIVE`는 저장값 동일·수식 진부분집합인지, 동등 `REFERENCE`는 저장값·확장 수식이 모두 같은지 확인한다.
- S001~S005 중 FAIL이 있으면 R010 이후의 계산을 실행하지 않는다. 파일명이나 저장시각만으로 개정 권위를 추정하지 않는다.

## R010 — 구성단가 합계 검산 (EMS)

- 적용: EMS `공종별내역서`에서 재료·노무·경비 단가와 총단가가 모두 있는 품목
- 입력: 재료단가 `M`, 노무단가 `L`, 경비단가 `E`, 총단가 `U` (KRW)
- 식: `expected = M + L + E`
- 판정: `abs(U - expected) <= KRW 허용오차`이면 PASS, 아니면 FAIL
- 누락: 구성단가 또는 총단가가 없으면 NOT_EVALUATED
- 근거: 내역ID와 원본 XLSX 행

## R011 — 내역 산술 검산

- 입력: 수량 `Q`, 단가 `U`, 금액 `A` (KRW)
- 일반 내역 식: `expected = Round(Q × U, 0, AwayFromZero)`
- EMS 내역 식: `expected = TRUNC(Q × M, 0) + TRUNC(Q × L, 0) + TRUNC(Q × E, 0)`
- 판정: `abs(A - expected) <= KRW 허용오차`이면 PASS, 아니면 FAIL
- 누락: 일반 내역은 Q, U, A, EMS 내역은 Q, M, L, E, A 중 하나라도 없으면 NOT_EVALUATED
- EMS에서 수량 셀이 비어 있고 금액 수식의 저장값만 0인 경우에도 Q=0으로 추정하지 않고 R011 NOT_EVALUATED로 남긴다.
- 근거: 내역ID와 원본 CSV 행
- F/H/J 저장 구성금액이 있으면 각 값을 Q×M/L/E 절사값과 별도로 대조한다. 구성항목 오류가 합계에서 상쇄되어도 FAIL이다.

## R012 — EMS 원가계산서 합계 검산

- 품목별 F/H/J 저장 구성금액(없으면 검산 가능한 Q×구성단가)의 합계와 `AS` 재료비 소계를 대조한다.
- 품목 노무비 합계 + `B2` 간접노무비와 `BS` 노무비 소계를 대조한다.
- 품목 경비 합계 + `C4,C5,C6,C7,CA,CB,CG,CH` 부가 경비와 `CS` 경비 소계를 대조한다.
- `S1 = AS + BS + CS`를 검산한다.
- `D3`~`D8`이 있으면 별도 공급가액 가산항으로 포함하고, `D9 = TRUNC((S1 + D1 + D2 + Σ(D3:D8)) / 10000, 0) × 10000`으로 만원 절사를 검산한다.
- `DB = TRUNC(D9 × 10%, 0)`, `DH = D9 + DB`, `S2 = DH + DK + DL + DM`을 검산한다. 없는 선택 비목은 0이다.
- `DK/DL/DM` 관급·폐기물 금액이 있고 품목 구성금액과 AS·BS·CS 중 한 소계가 다르면 어느 부분이 도급 소계에서 제외되는지 현재 입력만으로 증명할 수 없다. 일치하는 소계는 PASS로 검산하고, 차이가 있는 소계만 FAIL로 추정하지 않고 NOT_EVALUATED로 남긴다. S1 이후 내부 산술은 계속 검산한다.
- 요율의 법적 적정성은 L2 범위이며 R012가 판단하지 않는다.

## R020 — BIM 매핑 유효성

- 입력: 내역ID, 검산키, 단위, 계수
- 조건: 계수 > 0, QTO 행 존재, 내역·매핑 단위 동일, QTO `수량`은 중복 없는 양의 정수 요소ID 개수와 일치, 같은 내역ID·검산키 조합은 1회
- 실패: 조건 하나라도 충족하지 않으면 FAIL. 수량 비교는 `R021 NOT_EVALUATED`로 남긴다.

## R021 — BIM 수량 대조

- 입력: 내역 수량 `E`, 매핑된 QTO 수량 `B_i`, 계수 `M_i`
- 식: `expected = Σ(B_i × M_i)`, `delta = E - expected`
- 판정: `abs(delta) <= 수량 허용오차`이면 PASS, 아니면 FAIL
- 지원 단위: `EA`, `m`, `m2`, `m3`
- 누락: 내역 수량 또는 매핑이 없으면 NOT_EVALUATED
- 금지: 밀도, 손실률, 할증, 공제 및 표준품셈 수치를 암묵적으로 적용하지 않음

L2 표준품셈·단가 대조는 데이터 라이선스와 버전이 확정된 뒤 별도 규칙으로 추가한다.

## R030 — 입력 유효성

- 내역 파일에는 검산할 항목이 1개 이상 있어야 한다. 내역ID·검산키는 비어 있거나 중복될 수 없고, 내역ID는 Excel 수식 문자 `=,+,-,@`로 시작할 수 없다.
- 매핑이 존재하지 않는 내역ID를 참조하거나, 허용되지 않은 단위를 쓰면 FAIL이다.
- 허용 단위는 `EA`, `m`, `m2`, `m3`이며, 허용오차는 음수일 수 없다.
- 일반 내역 수량·단가·금액은 음수일 수 없다. 다만 EMS에서 수량과 금액이 모두 음수인 행은 공제·환입 조정으로 표시하며 R010·R011 산술만 검증하고 R021은 `NOT_EVALUATED`다. 단가는 조정 행에서도 음수일 수 없다.
- QTO의 수량·길이·면적·체적도 음수일 수 없다. 해당 QTO를 쓴 매핑은 R020 FAIL이다.
- QTO `검산키`는 비어 있지 않은 분류·패밀리·타입·레벨을 단위 구분자 `U+001F`로 연결한 UTF-8 SHA-256 대문자 64자리와 일치해야 하며, 대소문자 별칭을 포함해 같은 키의 집계행이 중복될 수 없다.
- QTO `요소ID`는 양의 정수이며 행 안과 QTO 전체에서 중복될 수 없다. `1`과 `01`은 같은 Revit 요소로 정규화한다. `수량`은 1 이상의 정수이고 해당 행의 요소ID 개수와 정확히 같아야 한다. 위반 행은 R030 FAIL이며 R021은 NOT_EVALUATED다. 요소가 하나도 없으면 QTO 데이터 행 자체를 만들지 않는다.
- 각 Finding의 근거에는 내역·매핑·QTO의 원본 행번호를 남긴다.

## R022·R023 — 역방향 커버리지 검토

- R022: 매핑되지 않은 BIM 집계행은 `REVIEW / INFO`로 표시한다. 공종 범위가 선언되지 않았으므로 자동 누락 오류로 단정하지 않는다.
- R023: 하나의 BIM 집계행이 둘 이상의 내역 항목에 매핑되면 `REVIEW / INFO`로 표시한다. 배분 근거가 없는 상태에서는 중복 계상으로 단정하지 않는다.
