# L2 데이터 사용권 확인 요청서

상태: **[검증필요]**. 이 문서는 발송용 초안이며, 회신 전에는 L2 단가·품셈 판정 기능을 구현하거나 판매하지 않는다.

수신 후보: 국토교통부 기술혁신과(표준품셈·표준시장단가 담당) 및 사용할 민간 단가 DB의 권리자.

제목: 건설공사 표준품셈·표준시장단가의 SaaS 검산 기능 이용 범위 문의

안녕하세요. Lukas QTO는 사용자가 보유한 내역서의 계산·수량 근거를 검토하는 소프트웨어를 준비하고 있습니다. 다음 행위가 가능한지와 적용 조건을 서면으로 확인 부탁드립니다.

1. 원문 또는 구조화한 항목 데이터를 서비스 내부 DB에 저장하는 행위
2. 항목명·코드·단위·산식·적용 시점 등 메타데이터를 기계판독 형식으로 가공하는 행위
3. 고객이 업로드한 내역서와 기준 데이터를 대조하고, 차이 결과만 고객 화면·CSV·PDF로 제공하는 행위
4. 고객 결과물에 기준 항목의 일부 문구·코드·적용 근거를 표시하는 행위
5. SaaS 구독료 또는 건별 검토 수수료를 받는 상업적 제공
6. 허용되는 경우 필요한 출처표시, 갱신 주기, 적용 제외 분야, 재배포 금지 범위

회신에는 적용 자료의 정확한 버전·발효일·권리자·허용 범위를 포함해 주시면 감사하겠습니다.

## 판정 기준

- 위 1~5 중 하나라도 불허 또는 불명확하면: L2 구현·판매 중단, L1만 유지
- 모두 허용되고 버전·갱신 조건이 명시되면: 별도 버전의 L2 규칙과 데이터 어댑터 설계 착수
- 보도자료의 공공누리 표시는 그 보도자료 자체의 이용 조건일 수 있으므로, 첨부 기준 데이터의 상업적 가공·재배포 허락으로 추정하지 않는다.
