## Scope

The approved Universal Workspace goal continues with four practical native example drawings and 24 original symbols connected to authenticated saved drawings. The existing four scaffold starters remain separate. Native model coordinates stay in millimetres; a persisted canvas output profile carries A3 landscape / 1:50 print intent.

Authority is an immutable database catalog and import receipt. Browser fields select known identities; they cannot establish authored bytes, license, approvals or source evidence. Native symbol imports use the existing operation history so already-connected participants can receive the definition before its instances.

The same 31 literal cases run in TypeScript and real PostgreSQL; every accepted case is actually persisted, and every rejected case is denied without changing saved data. Fractional scale metadata such as 1/3 is supported when its model dimensions are exactly representable (140×99), not every arbitrary fractional model dimension.
- PDF dialog summarizes all selected paper canvases, not just the active sheet. Audited draft export explains the existing approval prerequisite before rendering/uploading; preview export remains local. Server snapshot/approval authority is unchanged.
- Native paper fitting and pointer/object zoom share a lower 0.001 minimum. The former 0.05 floor cropped the full-size native model; no model coordinates were rescaled.
- Deferred measurement evidence is requested only for a visible schedule or a measurable selected-object inspector, after the existing save/checkpoint readiness conditions settle. Block-instance editing no longer starts irrelevant stale queries. Existing keepalive, strict checkpoint rejection and409 recovery remain unchanged; no console-error filter was added.
