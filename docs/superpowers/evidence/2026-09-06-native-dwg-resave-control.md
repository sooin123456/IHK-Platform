# Imported DWG resave control — accepted backend unit

전체 Universal Workspace 목표는 진행 중이다. 이번 완료 범위는 승인된 가져온 DWG의 재저장 요청·실행·취소를 제어하는 서버 기반이며, 다운로드·납품 완료나 운영 배포가 아니다.

## 구현·검증된 범위

- 브라우저는 도면 범위와 요청 ID만 전달한다. 서버가 실제 로그인 사용자와 승인 근거를 확인하고 기존 컴파일러로 정확한 편집 요청/근거 바이트를 고정한다.
- 독립 재저장 작업/시도 테이블과7개 제한 RPC. 프로젝트를 넘는 중복 요청, 변경 없는 요청, 용량, 최대3회 임대/재시도, 현재 권한, 오래된 시도 차단, 취소·실패 경쟁과 보존 삭제를 검증한다.
- 작업자는 최신 근거를 다시 컴파일해 일치 여부를 확인하고 기존 격리된 ACadSharp 엔진을 실행한다. 취소/권한 소멸/불확실한 제어 응답은 실행을 중단시키며, 실제 정리가 확인되지 않으면 취소·실패 성공을 기록하지 않는다.
- 기존 원본 파일·승인 개정·source-free 내보내기와 프로세스 생명주기를 보존한다. 새 의존성이나 별도 서버는 추가하지 않았다.

## 근거

포괄 회귀275pass, 실제 PostgreSQL1/1, 실제 DWG 처리·실행 중 취소1/1, 별도 복사본 타입 검사·빌드 통과. 최종 리뷰에서 부족했던 UUID 테스트를 보강했고 관련82/82 통과 및 독립 재검토까지 완료했다.82개는 기존 테스트와 겹치므로 합산하지 않는다.

실제 네이티브 테스트는 공개 합성 DWG와 실제 컨테이너를 사용하되 서비스 제어는 메모리 대역이다. 실제 DB 검증과 구분하며 Auth/Storage/브라우저 전체 흐름을 검증했다고 주장하지 않는다. 원본 SHA-256은 전후 동일하다. 파일은 여전히 experimental-unqualified / persistenceAuthority:not-issued이다.

## 다음 개발 단위

기존 저장/검증/내보내기 코드를 재사용하여 DWG·편집 요청·근거·보고서를 덮어쓰기 없이 저장하고, 업로드 종료와 취소 경쟁을 확인한 뒤 결과를 확정한다. 이후 최종 권한 재확인이 있는 다운로드와 실제 로그인→가져오기→편집→승인→재저장→재로그인→다운로드를 연결한다. [재사용 조사](2026-09-06-native-dwg-resave-control/next-publication-seams.md)는 준비 자료이며 아직 구현된 기능이 아니다.

현재 열린4173 미리보기와 기존 작업을 유지했다. 운영 배포·git 변경·원격 고객 DB/Storage 변경은 없었다. 검증용 임시 DB만 정리했고 재현 코드와 결과 기록은 보존했다. 대표 DWG의 외부 CAD 호환성 검증 및 정확한 승인 개정의 DWG/PDF/BOQ 납품 패키지는 여전히 남아 있다.
