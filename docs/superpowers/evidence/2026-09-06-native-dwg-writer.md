# 네이티브 DWG 저장기 — 구현·검증 기록

## 이번에 완료한 범위

기본 템플릿과 자체 제작 심볼의 CAD 명세를 **실제 편집 가능한 AC1024 DWG 파일로 저장하고, 저장된 도형·텍스트·치수·레이아웃을 다시 읽어 비교하는 내부 실행 경로**를 구현했다. 기존 오픈소스 ACadSharp3.7.1/.NET8을 재사용했으며 새 의존성을 추가하지 않았다. ponytail 원칙에 따라 별도 서버·상태관리·서비스 추상화 없이 기존 명령행 도구를 확장했다.

이 단위는 제품 전체의 DWG 지원 완료가 아니다. 앱의 승인 스냅샷 작업 연결, 기존 고객 DWG의 편집·재저장, 다른 CAD에서의 열기·출력·수신자 납품은 남아 있다. 화면·DB·운영 환경을 변경하지 않았으며, 커밋·푸시·배포·유료 계약도 수행하지 않았다.

## 실제 저장 동작

- `write-native` 명령이 엄격한 입력 검증 후 `native.dwg`, 바이트가 동일한 `source-manifest.json`, 검증 보고서를 새 디렉터리에 생성한다. 기존 경로와 원본은 덮어쓰지 않는다.
- 선·폴리라인·원·호·MTEXT·실제 aligned DIMENSION·해치·블록/INSERT를 개별 CAD 엔티티로 저장한다. 이미지나 DXF 중간 파일로 변환하지 않는다.
- 원본 객체 ID와 실제 저장 핸들·레이어·소유 블록의 계보를 유지하고, 양쪽 치수 화살표·측정값·텍스트 앵커까지 비교한다.
- 한글·명시적 줄바꿈·역슬래시·중괄호, 반전/회전/비균등 배율, 숨김·잠금 레이어, A3/1:50 및 사용자 지정 용지를 검사한다.
- 요청 선 굵기0.36mm→저장0.35mm, 요청 알파128/255→저장130/255 같은 엔진 정밀도 차이를 보고서에 명시한다.

입력의 SHA-256은 승인 증명이 아니다. 모든 결과는 `experimental-unqualified`, `not-qualified`, `independentCadVerification: not-performed`, `canonicalSourceValidation: producer-required`로 표시된다.

## 최종 검증

| 검사 | 결과 |
| --- | --- |
| .NET 빌드 | 종료0, 경고0, 오류0 |
| 네이티브 저장 자체 검사 | 13/13 통과 |
| 기존 CAD 도구 회귀 | 9/9 통과 |
| 별도 구현의 실제 DWG 도형·레이아웃 검사 | 7/7 통과 |
| 새 경로에 반복 저장한 실제 의미 데이터 비교 | 7/7 일치 |
| 배율 곱셈·이동 덧셈·곡선 외곽 오류 입력 | 3/3 검증 단계에서 종료2, 출력 미생성, 입력 보존 |
| 독립 사양·품질 리뷰 | 수정2회 후 승인, 열린 Critical/Important/Minor0 |

리뷰 과정에서 실제로 발견한 줄 간격, 누락된 도형/스타일 비교, 입력값 조기 검증, 과도한 경고 허용, 실패 보고서 경로 노출을 수정했다. 추가로 극단적인 블록 배율 오류를 실제 명령으로 재현한 뒤 차단했다. 블록 외곽은 한 번만 계산하고 인스턴스마다 네 모서리만 검사하여 반복 전체 검색을 피했다.

줄 간격은140mm 글꼴×1.2=168mm 의도를 보존하도록 native Exact factor0.72로 저장되는 것을 별도로 확인했다. 반복 검증은 실제 저장 의미 데이터의 일치를 확인한 것이며, DWG 헤더 시각을 포함한 파일 바이트 전체의 결정론성을 주장하지 않는다.

전체 해시·검증 결과: [verification.json](./2026-09-06-native-dwg-writer/verification.json). 초기 실패 파일·RED/GREEN 로그·리뷰 스냅샷은 로컬 단위 증거 디렉터리에 보존했다. 이번 변경은 .NET 도구에 한정되어 앱 전체 M1/브라우저 회귀를 새로 실행하지 않았다. 이전 M1 결과를 이번 실행 결과로 계산하지 않는다.

## 남은 제약과 다음 개발

동일 CAD 엔진으로 쓰고 읽었으므로 별도 검증 구현이 있어도 수신자 CAD 호환성 검증을 대신하지 않는다. 글꼴은 이름만 지정했으며 설치·임베딩·재배포·실제 글꼴 렌더링을 확인하지 않았다. 검증되지 않은 CAD 텍스트 제어 구문은 거절한다. 알려진 정확한 TableStyle.CellStyle 읽기 경고4개만 기록·허용하고, 그 외 경고는 실패 처리한다. 보수적인 외곽 검사는 극단적인 좌표 경계 입력을 거절할 수 있다.

1. 대용량 변환 전 벽별 개구부 인덱스를 추가한다.10,000객체 성능은 아직 검증하지 않았다.
2. 서버가 승인된 불변 스냅샷을 직접 읽는 멱등 생성 작업, 작업 임대, 결과 해시·게시 기록을 연결한다. 브라우저가 제출한 그래프나 PDF 내보내기 감사를 승인 산출물 권위로 재사용하지 않는다.
3. 기존 DWG 편집·재저장에서 수정하지 않은 객체를 보존하고, 라이선스가 확인된 실제30파일과 다른 CAD의 열기·재저장·출력·수신자 승인으로 검증한다.
4. DWG+PDF+허용된 글꼴/외부 참조 등 종속 파일+변경/호환성 보고서 납품 패키지와 실제3명 협업 흐름을 완성한다.

전체 개발 목표는 계속 진행 중이며, 이번 내부 저장기 완료를 R4/R5 전체 완료로 표시하지 않는다.
