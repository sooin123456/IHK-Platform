# Native CAD projection — 구현·검증 기록

## 결론과 범위

기본 템플릿 4종과 자체 제작 블록 심볼 24종을 편집 가능한 CAD 엔티티 명세로 변환하는 기반을 구현했다. 이번 단위는 **내부 CAD JSON 변환까지 완료**했다. 실제 DWG 저장·재열기, 기존 DWG 편집·재저장, 수신자 CAD 검증과 납품은 아직 완료하지 않았다. 운영 배포·커밋·푸시·유료 계약은 수행하지 않았다.

기존 TypeScript/Zod와 원본 그래프 검증·스타일·치수·개구부 계산을 재사용했다. ponytail 원칙에 따라 별도 서버·상태관리·서비스 추상화·의존성을 추가하지 않았다. 후속 파일 작성기는 이미 고정된 ACadSharp 3.7.1/.NET 8 실험 도구에 연결할 예정이다.

## 구현 내용

- 엄격한 버전 명세 `1hk-native-cad/1`과 순수 `buildDrawingCadManifest` 함수.
- mm 모델 좌표를 유지하며 Y축만 한 번 반전. A3 420×297 mm / 1:50 모델·종이 공간을 명시적으로 분리.
- 선·폴리라인·원·호·텍스트·치수·실제 해치 경계·블록 정의·INSERT를 구분하고 객체/블록 원본 ID의 계보를 보존.
- 벽 개구부를 실제 벽 경계에서 차감. 흰색 도형으로 가리지 않으며, 원형 채움도 원형 해치 경계로 보존.
- 숨김·잠금 레이어, 색·요청 선 굵기, 한글과 명시적 줄바꿈, 음수 블록 배율을 유지.
- 기존 렌더러의 객체 순서 알고리즘만 공유 함수로 추출. 원본 템플릿·심볼 정의와 DB·승인 모듈은 변경하지 않음.
- 잘못된 참조·좌표·프로필, 미지원 원본 배경/다중 캔버스, 과도한 입력을 명시적으로 거절.

출력은 항상 `experimental-unqualified`이다. 그래프 SHA-256은 내용 식별용이며 DB 스냅샷 해시, 권한, 저장 또는 승인 증명이 아니다. 글꼴 설치/재배포와 CTB/STB는 검증하지 않았으며, 표는 작성된 배치 좌표가 없어 메타데이터로만 보존한다.

## 실제 생성한 내부 명세

다음 파일은 합성 프로젝트 범위에서 생성했다. 인증된 승인 스냅샷 또는 DWG 파일이 아니다. 각 파일의 원본 그래프 및 파일 SHA-256은 [manifest.json](./2026-09-05-native-cad-projection/manifest.json)에 기록했다.

| --- | ---: | ---: | ---: |
| [실측 평면](./2026-09-05-native-cad-projection/measured-plan.cad.json) | 19 | 4 | 21,293 B |
| [사무실 배치](./2026-09-05-native-cad-projection/office-layout.cad.json) | 10 | 13 | 20,787 B |

별도로 계산한 수량·치수·문 위치·회전·실제 벽 개구부·용지/모델 크기와 비교해 일치했다. 네 원본 그래프와 자체 콘텐츠 정의 3개 파일의 해시는 변경되지 않았다.

## 검증 결과

| 검사 | 결과 |
| --- | --- |
| 새 변환 테스트 + 인접 회귀 테스트 | 133/133 통과, 실패·건너뜀 0 |
| 루트 TypeScript 검사 | 종료 코드 0 |
| 독립 사양/품질 리뷰 | 모두 승인, Critical 0 / Important 0 / Minor 1 |
| 전체 M1 브라우저 회귀 | 23/23 통과, 약 2.7분 |
| 앱·협업 빌드 | 모두 통과 |
| M1 실제 임시 DB 검사 | 5 통과, 설정 보호 조건에 따른 2 건너뜀 |
| 기존 CAD 실험 도구 자체 검사 | 9/9 통과 |
| 로컬 작업실·홈 화면 | HTTP 200, 콘솔·페이지 오류 및 오류 오버레이 0 |

전체 M1은 저장·협업·검토·승인·파일 진입과 기존 렌더러를 검사했다. 승인 후 동일 요청 재시도 200, 변경된 동일 ID/새 승인 상태 변경 요청 409, Viewer 변경 요청 403을 유지했다. 이번 PDF 회귀 산출물은 A3 420×297 mm이며 SHA-256은 `c0990e42b951c2c88c8a47df4abbe9dba0e086108e3817d84c7d1634ae1725ef`이다. 이번 단위에서 PDF 시각 검토를 새로 반복했다고 주장하지 않는다.

상세 결과와 소스 동결 해시: [verification.json](./2026-09-05-native-cad-projection/verification.json). 전체 실행 로그와 RED/GREEN·독립 리뷰·미리보기 캡처는 해당 단위의 로컬 증거 디렉터리에 보존했다. M1 임시 컨테이너 정리를 확인했으며 포트 4173의 로컬 미리보기를 복구했다. 미리보기는 시뮬레이션으로, 실제 인증·DWG 기능을 입증하지 않는다.

기존 빈 청크/번들 크기, 서명되지 않은 테마 쿠키, 색상 환경변수 경고는 남아 있다. 예상된 보호 상태 접근 거절과 공유 링크 반례의 설정상 미실행도 기록했다. 네이티브 편집자 탐색에서 `ERR_ABORTED` 요청 1건이 있었으며 콘솔·페이지·응답 오류는 0이었다. 모든 요청이 취소 없이 끝났다고 주장하지 않는다.

## 남은 필수 작업

1. 실제 ACadSharp DWG 작성기와 재읽기 비교: 엔티티·레이어·블록·치수·A3 레이아웃·1:50 뷰포트를 확인한다. 치수 생성 자식의 글꼴/색/텍스트 앵커, 투명도·선 굵기의 저장 정밀도 차이를 기록하고 검증한다.
2. 리뷰 Minor: 대용량 변환을 활성화하기 전에 개구부를 벽별로 한 번 인덱싱한다. 현재 벽마다 전체 객체를 정렬·검색하는 비용이 있으며 10,000개 객체 변환 성능은 검증하지 않았다.
3. 서버가 승인된 불변 스냅샷을 직접 읽는 권한·작업 임대·원본/산출물 해시 기반 생성 작업을 연결한다. 클라이언트 그래프 해시로 승인을 대신하지 않는다.
4. 기존 DWG 편집·재저장 시 건드리지 않은 객체를 보존하고 실제 수신자 CAD에서 열기·재저장·출력·납품을 검증한다. 같은 엔진의 재읽기만으로 호환성을 확정하지 않는다.
5. DWG+PDF+허용된 종속 파일+호환성/변경 보고서 납품 패키지를 완성한다. 글꼴·외부 참조·레이아웃·출력 스타일과 라이선스 범위를 확인한다.

이 단계들의 완료 전에는 제품의 DWG 재저장·납품 기능을 완료로 표시하지 않는다.
