# Native DWG writer and read-back

Implementation step within the approved Universal Workspace business/DWG design, not a replacement for R4/R5. User authorized continuous development without further approval prompts. Prior CAD projection is complete; current engine self-test baseline is 9/9. This adds the first real consumer of `1hk-native-cad/1` to the existing pinned .NET tool.

## Decision and boundary

Use existing ACadSharp 3.7.1 and .NET 8, not another CAD engine, SVG rasterization, DXF intermediate or a service abstraction. Add `write-native --input <manifest.json> --output-dir <new-directory>` to the existing CLI. It writes a real AC1024 DWG and immediately reads it back, comparing the requested model, blocks, layers, text, dimensions and paper layout against actual saved values. Existing qualification commands remain unchanged.

This is an internal executable native-drawing generation leg. It is not an authenticated app worker, an approved artifact receipt, existing-customer-DWG editing, independent CAD qualification or final delivery. Always report `qualification: experimental-unqualified`, `productionDwgDeliveryQualification: not-qualified`, `independentCadVerification: not-performed`. Never expose a public button or infer approval from the source graph SHA. Original DWG editing, server-authorized immutable jobs, licensed customer corpus and recipient delivery remain mandatory subsequent work.

## Input boundary and output

Consume the current exact geometry/field contract in `platform/app/lukas/lib/drawing-cad-manifest.ts`. Root and all consumed nested CAD fields reject missing/unknown/duplicate properties, malformed UTF-8/Unicode, non-finite values, invalid identities/references, wrong literal policies, negative/zero invalid geometry, nested block inserts, inconsistent entity lineage and profile/viewport dimensions. No optional JSON defaults silently invent geometry. Accept canonical optional style fontSize/systemKind fields exactly as declared. Model layer and block names must match their UUID-derived CAD names.

Canonical `metadata.structure` remains preserved opaque source evidence: recursively bounded finite JSON with expected collection envelope, not a second C# implementation of TypeScript architectural validation, source projection or canonical number hashing. Do not claim to revalidate or authenticate that graph in C#. Record `canonicalSourceValidation: producer-required` explicitly. The trusted application must run its existing schema/projection against the server-loaded immutable source; standalone CLI input is not authority. Preserve the input manifest byte-for-byte and its SHA-256; separately retain scope.structureSha256 as producer-declared content identity.

Before engine allocations: input at most 20 MiB, depth64, 1,000,000 JSON nodes, source-object/instance lineage10,000, blocks1,000, emitted model+block entities100,000, CAD primitive points100,000 (opaque source copies counted separately only by byte/node bounds), hatch boundaries4096. Check input type/size before reading the whole file. Reject duplicate JSON keys at every level, including metadata. Derived numbers and measurement calculations must remain finite. This CLI is internal only; CPU/memory/process hard limits and network isolation are required before an uploaded-file worker is exposed.

Reuse `QualificationPaths` physical-component/path-bound checks. Require input outside a fresh explicitly named output directory; refuse any existing output directory/file/symlink, including dangling aliases. Use exclusive create for outputs. No input mutation, no arbitrary external path/URL/font/Xref resolution. Fixed output names only: `native.dwg`, `source-manifest.json`, `native-report.json`. Read failures, invalid input, write/re-read mismatches, unwritable output/report stay within bounded CLI nonzero exits and never overwrite unrelated paths. Preserve partial diagnostic outputs on failure and label them failed; no claim of deliverability. Input/output safe filenames, hashes and scope in the public report; avoid absolute local paths and exception stack traces there.

## Editable CAD mapping

- WCS is already X-right/Y-up and in mm. Pass points directly, no second reflection, translation or print scaling. Use model units Millimeters and output AC1024.
- Actual LINE, LWPOLYLINE, CIRCLE, ARC, MTEXT, aligned DIMENSION, HATCH and ordinary BlockRecord/INSERT. Block-local layer0; model entities use mapped layers. Preserve authored model order and block primitive order. No exploding inserts, no flattening dimensions.
- Polyline closure and true polygon/circular hatch boundaries survive. HATCH is solid, non-associative, Z-up, with no external path. Read-back compares edges, radius/center, orientation and closure, not counts alone.
- Layers retain visible/locked state and Unicode source names in lineage. True-color RGB and requested paper lineweight are mapped to nearest supported native value with deterministic tie-breaking and explicit requested/stored diagnostics. Do not silently claim exact 0.36mm when stored0.35mm.
- Alpha/color conversion likewise records requested and actual stored transparency. Unsupported explicit alpha ranges must reject with a diagnostic rather than use ByLayer/ByBlock accidentally. Round-trip quantization is reported. Fully transparent objects, if supported, require an explicit non-dropping representation and corresponding read-back assertion.
- INSERT keeps signed X/Y scale, rotation and block reference; compare angles modulo2pi and transformed local basis, not only the insert origin. Blocks remain editable definitions with primitive-to-handle lineage.
- MTEXT uses the requested NotoSansKR-Regular.ttf text-style name only; no font file reads or embedding. Escape authored backslash/braces before converting authored newlines to paragraph markers. Reject unverified CAD control sequences such as %% and %<, and unsupported control characters, with an actionable error rather than interpreting them or claiming recipient-literal rendering from same-engine PlainText alone. Normal percent/Korean/newlines/backslash/braces remain supported. Preserve rotation through AlignmentPoint, font height, top-left origin, line spacing and requested width. Explicitly report the unresolved font-dependent wrap/visual qualification; no text truncation or screen ellipsis.
- Canonical text lineHeight is a dimensionless multiplier of fontSize, not a distance in mm. Native MTEXT LineSpacing is a multiplier of CAD's default3-on-5 spacing. Preserve the numeric baseline distance via `nativeFactor = lineHeight * 3 / 5`, with Exact spacing: canonical1.2 becomes0.72, independent of fontSize. Reject factors outside the native0.25..4 range before writing. Tests assert literal0.72 and baseline140×1.2=168mm, not a writer helper. [Autodesk spacing definition](https://help.autodesk.com/cloudhelp/2016/ENU/AutoCAD-LT-MAC/files/GUID-F94BE932-DA31-437E-9610-27F46ACD5711.htm), [native factor range](https://help.autodesk.com/cloudhelp/2024/CHS/AutoCAD-LT-ActiveX-Reference/files/GUID-429D5E20-4522-4699-BEC8-0D27CA17EDDF.htm).
- Dimensions remain true aligned DIMENSIONs with exact first/second/reference points and numeric measurement, precision1 and suffix ` mm`. Keep non-overridden measured value so later CAD edits can regenerate it. Preserve canonical textPosition as horizontal/top-left, not an arbitrary midpoint rotated along the baseline.
- Pinned engine `DimensionAligned.UpdateBlock` loses signed offset and places both arrowheads at its first reference point; generated MTEXT also needs actual style/font/color. Correct the actual anonymous dimension block using a small explicit geometry/style adapter if required. Do not settle for correct DIMSTYLE and wrong child graphics. Compare extension-line endpoints, both arrow tips, text style/anchor/content, native measurement and definition points after read-back. Any pinned engine mismatch that cannot be corrected must fail, not silently produce a valid-looking report.
- A3/default authored output profile becomes paper layout in millimeters and separate actual model viewport: width/height match paper, center matches paperCenter, ViewCenter matches viewCenter, ViewHeight matches model height; Height/ViewHeight matches1/scaleDenominator. Default paper viewport is distinct and must not produce Infinity in JSON. Preserve custom valid paper profiles too; no model rescaling.

## Evidence and comparisons

Use absolute geometric tolerance1e-7mm and angular tolerance1e-10 radians for read-back, stated before comparisons. Lineweight/transparency have explicit native quantization records, never a general relaxed comparison. Capture every requested entity-to-real-handle mapping and owning model/block record, plus generated dimension-child handles. Verify no requested entity was dropped, duplicated, moved to another owner/layer or changed in type/geometry. Retain original source object/instance and block primitive mappings, metadata and scope. Schema mismatch, missing handles or semantic differences make the command fail even if a DWG was written.

Reports compare input intent with actual read-back values, not only writer in-memory state against itself. Include DWG/input hashes, engine version, output profile, actual entity/layer/block/layout inventory, explicit tolerances, quantizations, reader/writer notifications and failures. Warnings never imply recipient approval. Same-input semantic outputs should match across fresh runs without requiring identical DWG bytes/header timestamps.

Real checks: all4 existing native manifests, all24 symbol definitions through the canonical producer, and literal edge cases covering ARC/CIRCLE/circular HATCH, mirrored/nonuniform INSERT, rotated literal Korean MTEXT, rgba, hidden/locked layers, diagonal/negative-offset DIMENSION and custom paper profile. Invalid/unknown/duplicate/cross-scope/oversize/path collisions fail. Add a negative comparison test by actually changing an emitted entity/read-back inventory; it must detect the loss/change. Keep old9self-tests green. No new test framework/dependency or UI/DB changes required.
