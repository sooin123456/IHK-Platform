## 화면 예시의 경계

- 객체 선택·변형·실행 취소는 정적 예시와 패널 상태의 체험이다. 실제 PDF/DWG 객체를 수정하지 않는다.
- PDF 열기/페이지/확대·이동은 실제 로컬 원본 보기다. PDF 원본은 그대로 유지한다.
- 입력은 React 메모리 상태다. 패널/경로가 해제되거나 새로고침하면 초기화될 수 있다. 모든 패널 간 초안 보존이나 복구를 보장하지 않는다. 새 원본을 선택하면 해당 화면 세션을 초기화한다.
- 가상 참여자·초대·검토·수신 확인은 실제 사용자, 승인 또는 전송 기록이 아니다.
- 물량·단가·금액은 기존 설명용 예시이며 발주 확정에 쓰지 않는다. 납품 구성의 내역도 미확정 예시다.
- DWG 재저장, IFC 로딩, 실제 개정 복원, 서버 권한 검증, outbox/협업 서버, 영구 저장, 계산, 발주, 결제, 배포는 이번 목표에서 제외됐다.
- 탄소 자료 예시는 가상 메타데이터다. EPD 인증이나 검증된 환경 근거가 아니며 탄소량은 미산정이다.
