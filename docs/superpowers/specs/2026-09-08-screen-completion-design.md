# 1HK 전체 화면 전용 완성 범위

사용자 승인 범위: 기존 3번 디자인 유지, 기능이 아니라 전체 화면, 반복 승인 없이 목표를 설정해 계속 개발. 신규 서버·계산·저장·배포 권한은 포함하지 않는다.

## 완료의 의미

프로젝트가 없는 사용자는 시작 화면, 기존 사용자는 프로젝트 목록에서 출발한다. 빈 도면/템플릿/로컬 PDF에서 동일 작업실로 진입하고 작성 도구·검토·물량/내역·납품 화면을 오간 뒤 원래 프로젝트로 복귀한다. 모든 예시 값·가상 참여자·상태 전환은 예시임을 표시한다. 파일 원본은 수정하거나 서버에 전송하지 않는다. DWG/IFC 엔진 성공, 접속자, 실제 결제, 계산, 승인, 저장을 연출하지 않는다.

## 코드 대조 결과 (2026-09-08)

기존: 홈/프로젝트, 빈 도면/2개 이미지 템플릿, 실제 PDF 열기/페이지/이동/확대, 레이어 표시, 도구 속성 일부, 페이지 댓글, 검토 상태 시뮬레이션, 공유/내보내기 시뮬레이션, A01→Q01→B01→원본 위치 복귀.

미완성: 작업실 구조/재사용 패널, 비교/3D/분할 진입, DWG 호환성/납품 준비, 프로젝트 관리 메뉴의 단순 안내, 업무 후속 화면과 각 예외 상태. 기존 레거시 기능이 존재하더라도 새 화면에서 접근 불가능하면 화면 범위에서는 미완성이다.

## 화면 목록과 검수

| 묶음 | 구현할 화면 | 완료 조건 |
|---|---|---|
| S1 작업실 구성 | 작업실 메뉴, 블록 검색·상세, 스타일 편집 예시, 사용자 속성, 공간/문/마감 스케줄 | 제목만 있는 안내가 아니라 선택·필터·상세·복귀 가능, Viewer 편집 제한 |
| S1b 작성 도구·문서 | 선/폴리라인/호/벽/개구부/공간, 치수·축척, 다중 선택·복사/회전/정렬, 실행 취소/명령 검색, 페이지·캔버스·레이어 표시/잠금 | 선택한 도구에 맞는 옵션과 예시 선택 상태, 실제 기하 편집·계산 없음, 없는 원본 객체를 선택했다고 주장하지 않음 |
| S2 원본·개정 | 2D/3D/분할, IFC 연결 대상/미연결, 개정 목록·비교·복원 확인, DWG 검사·의존 파일·보기 전용/실패 | 미검증 파일을 정상 판정하지 않고 예시 상태 선택으로 체험, PDF 맥락 유지 |
| S3 협업·전달 | 참여자/역할/초대 예시, 이슈 상태·활동 이력, 검토 상태별 전달, DWG/PDF/내역 납품 묶음과 수령 화면 | 기존 검토 흐름과 중복 저장 모델 없음, 실제 전송/승인/다운로드 없음 |
| S4 업무 연결 | 자재 행 상세, 발주 초안, 입고 확인, 탄소 근거 미등록/연결 예시 | 도면/물량 근거로 복귀, 승인되지 않은 양/금액을 확정 취급하지 않음 |
| S5 프로젝트·관리 | 개요, 참여자, 알림 상세, 라이브러리/템플릿 관리, 공간/조직·역할, 보존/복구, 이용 범위 | 기존 진입 유지, 관리 메뉴 중복 없음, 실제 계정/과금/삭제 없음 |
| S6 종합 검증 | 빈 시작/검색 결과 없음, Viewer, 로딩/오류/오프라인/충돌/승인 잠금, 모바일/키보드, 전체 복귀 경로 | 각 상태에 다음 행동과 탈출 경로, 전역 넘침 없음, 기존 테스트 유지 |

## 구조

기존 React·Dialog·Button·Lucide·PDF.js를 재사용한다. 작업실 내 보조 기능은 한 개의 `작업실 메뉴`로 묶고, 선택한 패널만 연다. 상단에 모든 기능 버튼을 늘리지 않는다. 신규 컴포넌트는 역할별로 분리하고 상위에서 도면 이름/페이지/Viewer/복귀 콜백을 전달한다. 실습 상태는 React 메모리에만 두고 새 원본을 열면 초기화한다.

AI 추천은 이전 결정대로 후속 범위이며 이번 화면 목록에 추가하지 않는다. 외부 오픈소스 조사·엔진 설치·실제 CAD 처리는 하지 않는다. 기존 라이선스 확인된 UI와 자산만 재사용한다. 기존 업무 기능·생산 경로·레거시 편집기는 변경하지 않는다.

## 검증/증거

Node/Vite SSR 회귀 테스트로 진입·빈 상태·권한·예시 고지·안전한 URL을 검증한다. 브라우저에서 검색→상세→복귀, 실제 PDF 맥락, 모바일 390px, 키보드 포커스를 확인한다. 격리 런타임에서 타입 검사와 빌드를 수행한다. 완료 상태는 아래 실행 계획 체크박스와 최신 검증 결과에만 근거한다.
