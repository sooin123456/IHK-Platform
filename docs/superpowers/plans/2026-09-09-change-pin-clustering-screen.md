# 변경 핀 묶음 — 화면 구현

범위: 동일 도면의 작성/검토 화면 개선. 실제 CAD 변경 감지·협업 전송·승인·배포는 제외.

## 반영

- 화면상 36px 이내의 변경 핀을 개수 배지로 묶음. 페이지별 처리, 원본 좌표 불변.
- 묶음의 개별 항목을 선택하면 기존 변경 상세·대화에 연결.
- 키보드로 펼친 목록 진입, Escape로 닫고 배지에 포커스 복원.
- 도형 배치 중 기존 도형이 클릭을 가로채는 문제 수정.
- 화면 크기에 따라 묶음을 다시 계산. 원래 목록 번호 유지.

## 검증

- 신규 좌표·페이지·확대 테스트: 구현 전 실패, 구현 후 통과.
- 신규 브라우저 묶음 테스트가 겹친 위치 배치 문제를 발견했고 수정 후 통과.
- 관련 단위/SSR 테스트 61/61, 브라우저 회귀 14/14, 타입 검사·빌드 통과.
- `/tmp/1hk-cluster.png` 직접 확인: 배지→항목 목록 및 도면·우측 목록 공존.
- 로컬 4181 미리보기 반영. 프로덕션 배포 없음.

## 남은 범위

- 선택 항목별 검토 요청 범위 UI, 이전 위치 복귀, 전체 A–G 플로우 점검은 별도 미완료.
- 대화·확인 표시는 화면 예시이며 서버 저장·실시간 협업이 아님.
- 대량 객체 성능 및 모든 화면 크기의 가장자리 팝오버 검증은 아직 미실시.
