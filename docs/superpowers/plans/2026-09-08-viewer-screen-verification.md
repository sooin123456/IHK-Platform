## 이번에 직접 확인한 동작

1. 검토 패널은 보기 전용이며 역할 전환·검토 결정 동작이 노출되지 않는다.
2. 선·사각형·원·텍스트·치수 도구가 비활성화된다.
3. 물량·내역 모달을 열면 영역 이름과 공종이 비활성화된다.
4. 물량 모달의 검토 연결은 같은 R3·1쪽을 표시한다. 물량 승인과는 별도라고 안내한다.
5. Escape로 모달을 닫으면 도면으로 돌아오고 물량·내역 열기 버튼으로 포커스가 복귀한다.

## 다음 검증 및 구현

- Viewer 작업실 메뉴의 스타일·속성과 공유·납품 설정을 브라우저에서 확인한다. 현재는 해당 단위 검사만 통과했다.
- Viewer로 프로젝트 목록에 복귀한 뒤 재진입해 역할이 유지되는지 확인한다.
- 파일 중복·새 개정 등록, PDF 페이지 선택과 목록 복원 등 미완성 시작 흐름을 구현 현황과 대조한다.

## 파일 시작 탐색 후속 보완

DWG·IFC 준비 화면에 같은 프로젝트의 파일 형식 선택으로 돌아가는 링크를 추가했다. 돌아갈 때 파일 이름·준비 설정이 초기화되며 프로젝트·기존 도면은 변경되지 않음을 링크 옆에 안내한다. 기존에는 창을 닫고 파일 시작을 다시 열어야 했다.

- 누락 링크 회귀 테스트 실패를 확인한 뒤 구현했다. dashboard/native-start 45개 통과, 타입 검사 exit 0.
- 로컬 빌드 exit 0, 기존 경고 유지. 4181 서버 session 79046 / PID 1052로 재시작했다.
- 브라우저에서 DWG 준비 → 파일 형식 선택으로 돌아가기 → PDF/DWG/IFC 선택 화면을 확인했다. URL의 동일 프로젝트 ID가 유지된다.
- IFC 복귀 링크는 SSR 검사만 수행했다. 파일 중복 처리·새 개정 등록은 이 수정에 포함되지 않으며 여전히 남아 있다.
