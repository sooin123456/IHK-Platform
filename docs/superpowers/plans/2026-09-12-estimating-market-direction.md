# 1HK 적산 중심 제품 방향 및 국내 시장 조사

2026-09-12 정리. 사용자와 논의한 기획 및 공개자료 조사 요약이며, 승인된 최종 사양이나 구현 완료 선언이 아니다.

## 제품 방향 제안

- 범용 도면 작업실의 기능 확장보다 요소별 수량의 정확성, 산출 근거, 검산, 변경 및 제출 호환성을 우선한다.
- 전체 적산 시장을 장기 대상으로 하되 공통 기반에 공종별 산출 규칙과 고객별 양식을 결합한다. 출시 지원 공종은 실제 검증한 범위만 표시한다.
- 한 요소에서 여러 산출 항목이 나오고 여러 요소가 한 내역 항목으로 집계될 수 있어야 한다.
- 원본/개정/위치 → 요소 → 치수/속성 → 기준/산식 → 공제/가산 → 수량 → 내역/단가 → 검토 기록을 연결한다.
- 형상 측정량, 기준 적용량, 계약·내역 적용량, 발주량을 구분한다. 부족한 근거는 임의 추정해 확정하지 않는다.

## 우선순위

집중: 다중 근거, 요소별 산출, 공종 규칙, 미산출/제외/확인 필요 상태, 중복 경고, 검산, Excel 양식, 변경 증감.

유지: 프로젝트, PDF/DWG/IFC, 개정, 단가 버전, 검토 및 이력. DWG 재저장·납품은 사용자 필수 요구로 유지하되 호환성 검증을 별도 과제로 둔다.

보조: 3D는 수량 근거 확인용, AI는 분류·누락 의심·이상 수량 추천용으로 둔다. 실제 AI 실행과 자동 확정은 구현된 것으로 표시하지 않는다.

초기 상품 보류 제안: 실사 렌더링, 발표 갤러리, 전체 공정관리, 발주·입고 실행, 자산 인계, 탄소. 기존 코드를 삭제한다는 결정은 아니다.

## 시장 조사 관찰

- 국내 적산 고객은 적산 전문업체, 종합건설사 견적·공무, 전문건설사, 설계·엔지니어링, 발주처·CM·감리로 구분한다.
- 독립적인 국내 적산 소프트웨어 총매출/점유율 통계를 이번 조사에서 확보하지 못했다. 건설공사 금액을 소프트웨어 시장 규모로 간주하지 않는다.
- 이지테크는 AutoCAD 산출, Excel 변환, C3R XML 생성 및 환경 조건을 공개한다. CAD/Excel 연결은 기본 진입 조건으로 판단한다.
- 글로텍 EBS는 일위대가, 직접·간접 공사비, 변경·기성, XML/Excel, 공동작업 제품군을 소개한다. 기존 제품에 협업·변경 기능이 없다는 주장은 하지 않는다.
- 한국교육시설안전원 공개 질의에는 특정 EMS 파일 요구로 외주 비용이 발생한다는 사례가 있다. 전국 발생률을 나타내는 자료는 아니다.
- BIM 수량산출 연구는 견적용 모델과 프로세스 표준화 필요성을 다룬다. 모델 형상량을 계약 수량으로 자동 확정해서는 안 된다.
- 철도에는 이미 BIM 5D 개발 성과가 있으며, 2025.12 철도 BIM 적용매뉴얼 개정이 공개됐다. 실제 운영과 연계 가능성은 별도 확인해야 한다.

## 접목할 상품 가설

1. 적산 작업실: 요소별 산출, 공종 규칙, 검산, 기존 내역 도구 연결.
2. 적산 검토실: 브라우저 근거 확인, 항목별 질의, 제출/확정본, 변경 이력.
3. 변경 적산: 개정 영향, 수량/단가/기준별 증감, 근거 패키지.

첫 진입 가설은 기존 산출서 가져오기 → 도면 근거 연결 → 검산 → 변경 비교다. 독점 형식의 지원은 규격·협약·실제 호환성 확인 전 약속하지 않는다. 단가 데이터 이용·재배포 권한도 별도 확인한다.

## 검증 제안

고객 8~12명과 실제 프로젝트 3세트(원본/수정 도면, 산출서, 내역서, 검토 의견, 최종본)를 확보해 항목별 오차·누락·중복, 근거 탐색 시간, 변경 반영 시간, 제출 변환 시간, 재작업과 지불 의사를 측정한다. 아직 확보된 표본이나 확인된 개선율은 아니다.
