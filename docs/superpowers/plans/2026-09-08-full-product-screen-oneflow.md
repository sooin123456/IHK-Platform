## 목표와 판정

활성 목표 '이걸 완성해줘'는 직전 사용자가 승인한 전체 화면 구현 프롬프트 A–G 및 10개 브라우저 시나리오를 뜻한다. 이전 제한된 D01 검토 목표의 완료를 제품 전체 완료로 재사용하지 않는다.

실제 CAD 엔진, 서버 저장/권한 변경/협업 전송/계산/결제/운영 배포는 제외한다. 화면은 실제 기능처럼 거짓 성공을 표시하지 않으며 로컬 예시 상태를 연결한다. 신규 라이브러리 없이 기존 React, UI 컴포넌트, PDF 렌더러를 재사용한다.

## 작업실 탭 초안 보존 회귀

재현: 로컬 4181 작업실 메뉴 → 블록 검색에 `책상` 입력 → 스타일 → 블록·라이브러리. 수정 전 검색 input의 DOM value는 빈 문자열이었다.

수정: 방문한 작업실 섹션을 안정된 key로 유지하고 비활성 섹션을 hidden 처리한다. 미방문 섹션은 아직 마운트하지 않는다. 원본 파일이나 서버에는 저장하지 않는다.

검증: 기존 workbench SSR 검사 5/5 통과. 타입 검사와 클라이언트/서버 빌드 통과(기존 cookie·청크·localStorage 경고 있음). 로컬 4181 새 빌드에서 블록 검색 `책상`과 스타일 이름 `현장 검토`가 탭 왕복 뒤 DOM snapshot에 유지됨을 확인했다. 비활성 패널은 접근성 snapshot에 노출되지 않았다. 확인 시점 브라우저 error 로그는 0개였다. 자동화 locator evaluate 한 번은 관찰 타임아웃이었고, 뒤이은 실제 DOM snapshot으로 결과를 확인했다. 메뉴 닫기 보존까지 검증한 것은 아니다.

잔여: 메뉴 닫기/재열기 시 parent key와 Dialog unmount에 의한 초기화, 원본·개정 내부 탭의 별도 초기화는 여전히 해결해야 한다. 이번 수정으로 C 전체를 완료 처리하지 않는다.

## 프로젝트 즐겨찾기 화면

`workspace-dashboard.tsx` 미리보기 모드에 카드별 즐겨찾기 추가/해제, 즐겨찾기 필터, 빈 상태를 추가했다. 버튼은 프로젝트 링크 밖에 있어 별을 눌러도 프로젝트로 이동하지 않는다. 검색과 즐겨찾기 필터는 교집합으로 적용되고 격자/목록 보기 모두 같은 상태를 사용한다. sessionStorage는 미리보기 전용 키를 사용하며, 저장 실패 시 현재 화면에서만 유지된다고 안내한다. 운영 계정 저장이나 서버 권한 변경은 없다.

새 SSR 회귀 검사 실패를 확인한 뒤 구현했다. dashboard 관련 검사 34/34, 타입 검사 및 빌드 통과(기존 경고 있음). 브라우저 4181에서 다음을 직접 확인했다.

1. 성수동 사무실 즐겨찾기 추가 → 즐겨찾기 필터에 해당 프로젝트만 표시.
2. 프로젝트 상세 진입 → 모든 프로젝트 복귀 → 별의 aria-pressed=true 유지.
3. 즐겨찾기에서 해제 → 즐겨찾는 프로젝트 없음 및 검색 초기화 표시.
4. 공유받은 판교 프로젝트 추가 → 목록 보기 → 성수 검색 → 조건에 맞는 결과 없음.
5. 검색 초기화 → 즐겨찾기 → 판교 프로젝트 한 개와 해제 버튼 표시.

잔여: 목록의 검색어·필터·보기 방식은 프로젝트 왕복 후 초기화된다. 즐겨찾기 선택 자체만 유지된다. 저장 차단 예외의 브라우저 재현, 모바일 별 버튼 시각 검증은 아직 하지 않았다. A 전체 완료 아님. 다음 우선순위는 미리보기 프로젝트 생성→빈 프로젝트→도면 시작과 DWG/IFC 진입이다.

## 로컬 프로젝트 생성과 도면 진입

신규/기존 홈의 `새 프로젝트` → 이름/설명 양식 → 0개 도면/원본의 빈 프로젝트를 구현했다. 프로젝트 레코드는 미리보기 전용 sessionStorage 키로 보관한다. 서버 저장·조직 권한·운영 데이터는 변경하지 않는다. 저장 공간 오류는 화면에서 경고한다. 복원 파서는 미리보기 ID 형식과 필수 문자열을 검증한다.

고정 fixture 3개만 허용하던 도면 진입/복귀 경로를 미리보기 프로젝트 전용 ID 범위까지 확장했다. 임의 외부 주소는 허용하지 않는다. 빈 프로젝트에는 기존 샘플 도면/파일을 섞어 넣지 않는다.

검증: 신규 회귀 실패 확인 후 구현. dashboard 관련 37/37 통과, 타입 검사/빌드 통과(기존 경고 존재). 브라우저에서 공백 이름 제출 오류 → `화면 검증 현장` 생성 → 0개 도면 표시 → `새 도면` → `검증 평면` 작업실 → 작업공간으로 돌아가기 → 같은 프로젝트 이름/ID 복원을 확인했다.

미완료: 도면을 시작해도 프로젝트 도면 목록에는 아직 저장되지 않는다. 로컬 복원 직전 기본 목록이 잠시 표시된다. 신규 빈 프로젝트의 개요/검토 등 보조 패널은 여전히 일반 샘플이므로 빈 상태에 맞춰 통합해야 한다. 미리보기용 프로젝트 생성은 구현됐지만 A/B 전체 완료 아님.

현재 검증 서버: 기존 루프백 4181, 실행 session 86842 / PID 88031 (후속 작업에서 재확인 필요).

## 빈 프로젝트 문맥 보완

새 로컬 프로젝트의 검토·물량·자재·참여자·개요 패널에서 기존 샘플 이력을 제거하고 해당 업무의 빈 상태와 시작 안내를 제공한다. Viewer에는 도면 생성 링크를 노출하지 않는다. 로컬 프로젝트가 복원되기 전에는 복원 중 상태를 표시하며, 복원 후에도 없으면 탭 한정 보관의 한계와 목록 복귀 경로를 안내한다. 무관한 예시 프로젝트 목록을 먼저 보여주지 않는다.

신규 SSR 회귀 2개 실패 확인 후 구현했고 dashboard 관련 39/39 통과했다. 타입 검사와 빌드 통과(기존 경고 있음). 새 빌드 브라우저에서 복원 중→같은 프로젝트로 복원됨과 검토 패널에 `아직 검토 요청이 없습니다` 및 같은 프로젝트의 시작 링크를 확인했다. 나머지 빈 패널과 복원 불가 분기는 브라우저 검증이 남았다. 만든 도면이 목록에 남도록 하는 화면 세션 연결은 여전히 다음 작업이다. 현재 서버 session 84795 / PID 88507, 기존 4181 포트.

## 도면 목록 보관 및 다시 열기

프로젝트에서 빈 도면 또는 템플릿 시작 시 제목·시작 종류·용지·프로젝트 ID·수정 시각을 미리보기 전용 sessionStorage에 보관한다. 프로젝트별 도면 목록에 합치고, 다른 프로젝트에는 노출하지 않는다. 목록과 홈 이어하기 모두 동일한 시작 종류·용지로 다시 연다. 프로젝트 개요에는 보관된 도면 개수를 표시하며 편집·검토·물량 데이터 연결과 구분한다.

새 회귀 실패를 확인한 후 구현. dashboard/return 관련 45/45 통과, 타입 검사와 빌드 통과(기존 경고 있음). 브라우저에서 `화면 검증 현장` → `목록 유지 검증` A2 빈 도면 시작 → 프로젝트 복귀 → 1개 도면 및 `startKind=blank&paper=A2` 링크 → 재열기 → 동일 제목과 A2 빈 도면 문구를 확인했다. 확인 시 브라우저 error 로그 0개.

범위 제한/후속: 도형·댓글·검토 reducer 상태는 목록 레코드에 보관하지 않는다. PDF는 파일 핸드오프와 재선택 복구 설계가 남았다. 프로젝트 없는 홈 시작의 자동 분류, 템플릿 왕복 브라우저 검증, 저장 차단 시 양식 안의 오류/재시도 UX, DWG/IFC 시작은 미완료다. 전체 목표 완료 아님. 현재 4181 서버 session 31054 / PID 89024.

## DWG/IFC 준비 화면 첫 연결

`DrawingNativeStartPreview` 추가. 프로젝트/홈의 파일 시작 화면에서 `start=dwg|ifc` 준비 화면으로 연결하고 동일 프로젝트 복귀 및 Viewer 진입 제한을 유지한다. 파일 이름 선택 또는 파일 없는 예시 체험 → 준비 조건 → 실패/복귀 → 미연결 작업실 화면으로 이어진다. DWG는 모델/레이아웃·외부참조/SHX/미지원 객체 안내 및 재저장·재열기·납품 검증 조건을 표시한다. 엔진이 없으므로 실제 파일 생성 버튼은 비활성이다. IFC는 3D/분할 선택을 실제 작업실 초기 보기로 전달한다.

검증: 새 컴포넌트 및 경로 회귀 실패 확인 후 구현, 관련 53/53 통과. 타입 검사/빌드 통과(기존 경고). 브라우저에서 DWG 예시 → 레이아웃 선택 → 누락 안내 → 납품 파일 생성 비활성 → 실패/복귀 → `DWG 레이아웃 화면 예시` 진입 확인. IFC 예시 → 분할 보기 진입(aria-pressed=true) → `연결된 IFC 모델이 없습니다` 확인. 브라우저 error 로그 0개.

잔여: 준비 단계 선택과 파일 이름은 작업실 왕복 시 보존되지 않는다. 준비 중/취소, 중복/새 개정 등록, 실제 파일명 선택의 브라우저 검증, 통합 파일 선택 UI(현재 PDF 화면 하단에 CAD 진입점), DWG 납품 패키지의 세부 화면 연결과 화면용 객체 편집은 추가 작업이다. 원본 파일 바이트는 읽거나 업로드하지 않았으며 실제 CAD 해석/생성 기능은 구현하지 않았다. B/F 전체 완료 아님. 현재 로컬 서버 session 73841 / PID 89730, 포트 4181.

## 검토 개정 이력

review-loop reducer의 수정 반영/승인 후 새 개정 전환에 이전 개정 스냅샷을 추가했다. 페이지·기준/변경 위치·요청 내용·위치 의견·당시 검토 상태를 보관한다. 새 개정의 변경이 과거 스냅샷을 바꾸지 않는다. 검토 패널의 `이전 개정`에서 과거 예시 도형과 요청/의견을 읽기 전용으로 펼쳐 볼 수 있다. Viewer도 조회만 가능하다.

새 회귀 2개 실패 후 구현. review/PDF/delivery/takeoff 관련 34/34 통과. 타입/빌드 통과(기존 경고 있음). 브라우저에서 변경→검토 요청→검토자 비교→승인→작성자 새 개정→R2 변경→R1 펼치기를 수행했다. R1의 승인 상태, 읽기 전용, 위치1→2, 원래 요청 내용과 보관 도형 표시가 유지됨을 확인했다. 이 기록은 현재 작업실 메모리이며 페이지 새로고침·재열기 영속 보관은 미구현이다. 원본·개정 보조 화면의 별도 샘플 비교와의 통합도 남았다. D 전체 완료 아님. 현재 4181 서버 session 47010 / PID 90257.

## 도면별 검토 기록 복원 연결

프로젝트 목록·이어하기·새 도면 시작 경로에 screenDocument UUID를 전달한다. 작업실은 해당 식별자로 sessionStorage의 검토 reducer 상태와 개정 이력을 보관/복원한다. 제목을 저장 키로 사용하지 않는다. 복원 데이터의 구조·단계·숫자·문자열 길이를 검증하며 복원 뒤 focused/compared를 초기화해 비교 확인을 다시 요구한다. 다른 원본을 선택한 뒤에는 이전 도면 기록에 쓰지 않는다. Viewer는 로컬 저장을 변경하지 않는다. 저장 오류/손상은 안내하고 기존 손상값을 자동 덮어쓰지 않는다.

## 작업실 메뉴 닫기·재열기 초안 유지

메뉴 열기마다 부여하던 세션 key를 제거하고 원본 변경 기준 key만 유지한다. 기본 dialog의 showModal/close로 표시를 전환하며, 첫 열기 이후 양식은 마운트된 상태로 보관한다. 닫힌 메뉴는 모달로 노출하지 않고 Escape와 돌아가기 버튼에서 열기 버튼으로 포커스를 복귀한다. 안내 문구는 도면을 열어 둔 동안 유지하고 새로고침 시 초기화됨을 명시한다.

이번 검증: 관련 workbench/PDF/review 테스트 28/28 통과, 타입 검사 및 빌드 exit 0(기존 경고 존재). 새 빌드 브라우저에서 스타일 이름 `닫기 보존 검증` 입력 → 닫기 → 재열기 → 스타일 값과 미리보기 유지 확인. Escape 후 표시된 dialog 0개와 activeElement의 aria-label `작업실 메뉴 열기` 확인. 작성 도구 버튼으로 재진입해 해당 도구 화면 표시 확인. 조회한 브라우저 error 로그 0개.
