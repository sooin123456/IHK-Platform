### C/D/F 선택 도형의 검토 개정 연결 — 최신 확인

원인: chooseFile은 모든 유효 PDF 선택에 sourceVersion 증가, page=1, review reset, 댓글/레이어 초기화를 적용했다. 따라서 동일 파일 재선택도 교체로 처리되고 이후 검토 저장 가드에서 제외됐다.

기존 해시 없는 문서 또는 다른 원본은 초기화 경고와 확인 후 별도 임시 원본으로 열며 기존 보관 기록을 덮어쓰지 않는다. 취소/해시 오류는 현재 상태를 유지한다. 빠른 재선택과 unmount 이후 이전 비동기 선택 적용을 방지한다. 일반 검토 복원에서도 저장된 page를 복원하도록 수정했다.

### T4 요청·답변 초안 분리 및 복원 — 검증 완료한 부분

기존 브라우저에서 답변 새로고침 후 빈 입력, 자료 A 요청이 자료 B로 따라오는 문제를 먼저 재현했다. 두 기대값 검사 모두 실패했다. project-sharing-preview.tsx의 동일 초안 훅을 내부 답변과 외부 요청에 재사용하여 요청은 프로젝트/초대/대상/예시 작성자별, 답변은 프로젝트/요청 ID별로 sessionStorage에 보관한다. 외부 참여자 정보 자체는 자동 인증으로 복원하지 않으며 같은 예시 이름·소속을 다시 입력하면 해당 초안만 연다.

초안은 ID를 갖는다. 요청 ID와 답변 이력의 선택적 ID에 제출한 초안 ID를 기록해, 디스크에 제출 전 초안이 남아도 다시 복원/중복 등록하지 않는다. 기존 ID 없는 답변 이력은 유지한다. 이력 중복 방지 단위 검사는 수정 전 2개 중복으로 실패, 수정 후 1개 보존으로 통과했다.

탭 저장 실패는 입력을 먼저 유지하고 오류/재시도를 표시한다. 실패한 초안만 메모리에 남겨 항목 전환 시 복구하며, 미보관 입력이 있는 동안 새로고침·탭 닫기 경고를 등록한다. 재시도 성공 또는 제출 성공 후 경고를 해제한다. 이는 브라우저 종료 이후 영속 복구가 아니며, 저장 오류를 무시하고 브라우저를 종료하면 메모리는 유지되지 않는다. 새 상태관리 라이브러리나 서버는 추가하지 않았다.
