## 지금 확정할 범위

**L1만 판매·실증한다.** Revit QTO와 사용자가 승인한 매핑을 근거로 내역 산술·수량 차이·추적성만 판정한다. 숫자 판정에는 LLM을 사용하지 않으며, 표준품셈·시장단가의 정답을 주장하지 않는다.

정부 서비스와의 차별은 다음으로 한정한다. 이는 현재 공개 기능 비교에 따른 **[가정]**이며, 실제 조달 범위·제품 사양이 공개되면 다시 검증해야 한다.

- 제출 전 현장 사용자가 직접 돌리는 Revit 수량 ↔ 내역서 대조
- 각 수량 차이를 원본 요소ID와 승인 매핑으로 되짚는 증거 체인
- 특정 공공기관의 내부 예정가격 작성이 아닌, 설계사·원가계산용역사·감리의 다중 양식 품질검토

이 포지션은 조달청의 내부 AI 도입과 정면으로 기능 경쟁하기보다, 원가계산 용역사·설계사·감리의 제출 전 품질검토에 집중하는 가설이다 `[가정]`. 검증 결과와 근거가 남는다는 점이 L1의 차별 조건이다 `[가정]`.

## L2 착수 금지 조건

다음 세 증거가 모두 생기기 전에는 L2 규칙·DB·가격 판정을 구현하지 않는다.

1. 권리자 또는 공급사의 서면 라이선스: 저장, 가공, SaaS 제공, 고객 결과물 재배포 범위.
2. 적용 기준의 버전·발효일·공종 범위·갱신 주기.
3. 최소 2개 실제 프로젝트의 원본 내역서와 적산 전문가의 기대 판정.

## 다음 검증 순서

1. 제공된 Revit 2017 본파일 후보를 담당자가 승인하고 Windows/Revit에서 QTO CSV 하나를 생성해 요소ID 역추적을 확인한다.
2. ZG·ZJ의 콘크리트 계열·형틀 계열·철근 버킷을 세부항목·할증·범위·층·부재 기준으로 분해한다.
3. 원가계산 실무자에게 L1 결과와 구조수량 차이 10건을 검토받아 `PASS/FAIL/REVIEW`의 오판 여부를 기록한다.
4. 위 결과가 유효하면, L2 권리자에게 서면 라이선스 질의를 보낸다.
