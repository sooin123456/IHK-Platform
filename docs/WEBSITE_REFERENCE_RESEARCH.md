## 관찰한 패턴

### 국내 대형 건설사

- 대표 프로젝트 이미지를 화면 전체에 사용해 규모와 수행 능력을 먼저 전달한다.
- 첫 화면 문장은 짧고 사업영역, 프로젝트, 기술, ESG, 뉴스로 확장한다.
- 회사의 연혁과 글로벌 규모를 수치로 보여 신뢰를 만든다.

### 해외 적산·비용 컨설턴트

- `Cost certainty`, `value`, `risk`, `independent advice`처럼 고객의 의사결정 결과를 전면에 둔다.
- 서비스 목록을 프로젝트 생애주기와 연결한다: 타당성 검토 → 비용계획 → 조달 → 변경관리 → 준공.
- 프로젝트 사례, 시장 인사이트, 벤치마크 데이터, 담당 전문가를 신뢰 근거로 사용한다.
- BIM은 단독 상품이라기보다 비용·리스크·진행 데이터를 연결하는 도구로 설명한다.

## 한길시스템 적용 결정

1. 건설사의 강한 건축 이미지를 사용하되, BIM 와이어프레임을 결합해 서비스 정체성을 한 화면에서 보여준다.
2. 첫 문장은 기능이 아니라 고객 가치인 `설계에서 물량까지, 근거를 연결합니다`로 정리한다.
3. SINCE 1995, BIM 객체 기반, SHA-256 원본 증명, Revit 2025 베타를 신뢰 스트립으로 노출한다.
4. 서비스는 BIM 모델링·물량산출·내역서/공사비 3축으로 유지하고 각 납품물을 함께 표기한다.
5. IFC·QTO·요소 원장·검토 기록을 `고객이 받는 결과물`로 별도 제시한다.
6. 해외사처럼 비용 확실성·독립 검토·변경관리를 말하되, 아직 없는 글로벌 규모·고객사·자동 비용 예측은 주장하지 않는다.
7. 실제 프로젝트 사진을 확보하기 전까지 AI 생성 이미지는 영웅 영역의 브랜드 이미지로만 사용하고 실적 사례로 오인시키지 않는다.

## 후속 콘텐츠 조건

- 실제 고객 프로젝트 공개 동의를 받으면 프로젝트 유형, 수행 범위, 결과물, 개선 효과를 같은 구조로 추가한다.
- 비용 벤치마크·시장 인사이트는 검증된 자체 데이터가 축적된 뒤 추가한다.
- KOTO는 접속 가능한 환경에서 모바일·데스크톱 화면을 캡처한 뒤 정보 구조와 전환 흐름을 별도 비교한다.
