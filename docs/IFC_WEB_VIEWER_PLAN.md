# IFC 웹 시각화 계획

## 목표

설치 프로그램 없이 한길시스템 웹 프로젝트에서 등록된 IFC 원본을 열어 다음 작업을 수행한다.

1. 모델 회전·이동·확대/축소
2. 전체 모델 또는 선택 요소 화면 맞춤
3. 3D 형상과 요소 목록의 양방향 선택
4. Express ID, IFC 유형, Global ID, Property Set 확인

뷰어는 원본을 읽기만 한다. 물량을 다시 계산하거나 IFC·QTO·승인 결과를 변경하지 않는다.

## 최소 구조

```text
Supabase 비공개 IFC
  → 권한 확인
  → 5분 signed URL
  → 브라우저에서 1회 다운로드
  → web-ifc 0.0.77로 속성·형상 해석
  → Three.js로 3D 표시
  → 선택 Express ID로 기존 속성 패널 연결
```

기존 업로드, 프로젝트 권한, 파일 확인번호, 속성 탐색 경로를 그대로 사용한다. 별도 변환 서버나 Autodesk 외부 서비스는 도입하지 않는다.

## 1차 제공 기능

- 원본 색상 기반 3D 모델
- 마우스·터치 카메라 조작
- 모델 전체 보기
- 선택 요소 보기와 강조
- 모델 클릭 시 속성표 동기화
- 목록 클릭 시 모델 선택·카메라 이동
- WebGL 오류 시 기존 요소·속성 탐색 유지
- 페이지 이탈 시 IFC/WASM/WebGL 메모리 해제

## 안전 경계

- IFC 원본과 signed URL을 로컬 저장소에 남기지 않는다.
- 브라우저 형상 표시는 적산 수량의 공식 근거가 아니다.
- 75MB를 초과하는 IFC는 1차 버전에서 3D 생성을 생략하고 속성만 표시한다.
- 고객 IFC는 테스트 저장소에 복사하지 않는다.
- `web-ifc`는 MPL-2.0, Three.js는 MIT 라이선스 고지 대상이다.

## 검증 기준

- 실제 Revit IFC에서 요소·형상·삼각형이 1개 이상 읽힌다.
- 전체 보기 후 모델이 화면 안에 들어온다.
- 3D 클릭과 목록 클릭이 같은 Express ID·속성을 표시한다.
- 빠르게 여러 요소를 선택해도 마지막 선택의 속성만 남는다.
- WebGL을 사용할 수 없어도 목록과 속성은 계속 작동한다.
- 화면 이탈 후 renderer, controls, geometry, material, IFC model이 해제된다.
